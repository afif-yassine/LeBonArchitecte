# Cahier des charges

Ce dossier est la **source de vérité** du projet. Tout ticket, toute décision et tout agent s'appuie sur lui.

- `cahier-des-charges.md` : le texte du propriétaire (version d'origine plus ajouts datés). Ses exigences sont numérotées (E0 à E20, A1 à A13) ; chaque ticket cite celles qu'il couvre.
- Les maquettes, captures et annexes se déposent ici aussi.

Règles :
1. On ne modifie pas le texte du propriétaire : on ajoute une section datée.
2. Une exigence sans ticket apparaît dans l'écran « Cahier des charges » de la plateforme.
3. Les agents reçoivent seulement les exigences de leur ticket, jamais le dossier entier.
